STEP 2

在 Cloud Shell 一鍵準備 Antigravity 與驗收 Skill

開啟 Google Cloud Shell，點擊下方按鈕複製整段指令貼入終端機並按 Enter。這會自動安裝/更新 agy、建立《爌肉之城》專用的驗收方法包（SKILL.md）並確認版本： 

curl -fsSL https://antigravity.google/cli/install.sh | bash
export PATH="$HOME/.local/bin:$PATH"
mkdir -p ~/kbp-lab/.agents/skills/website-audit && cd ~/kbp-lab

cat << 'EOF' > ~/kbp-lab/.agents/skills/website-audit/SKILL.md
# Metadata
- Name: website-audit
- Description: 針對 AI Studio 生成之行銷網站進行出貨前三大關卡驗收，並直接在終端機輸出判定結果與修正指令。

# Goal
你是一位嚴格把關出貨品質的軟體公司技術長。請針對使用者提供的「網站公開網址 (URL)」或「直接貼上的 HTML 原始碼」進行三大關卡驗收，並直接在終端機畫面印出完整驗收報告。

# Workflow
1. 步驟零：讀取網頁內容（若提供網址請用瀏覽器工具或 curl 讀取；若無法存取網址，請提示使用者直接把 HTML 程式碼貼進對話框驗收）。
2. 關卡一（行銷目的與 LINE CTA）：檢查是否包含主標題、主視覺 002.jpg、1+1+1 組合，且必須有明確按鈕連往真實的「彰化旅行+」LINE 網址（lin.ee 或 line.me）。若連往 #、空連結或假表單，判定不合格。
3. 關卡二（60 歲長輩手機體驗）：內文字體必須在 18px (1.125rem / text-lg) 以上。只要發現使用 12px、14px、text-xs、text-sm 等微字，列出證據並判定不合格。
4. 關卡三（防幻覺賠償護欄）：檢查是否擅自捏造未授權優惠（如折扣、買一送一、免運、抽獎、免費贈品或虛構售價）。

# Output Format
請直接在終端機畫面印出：
1. 【技術長驗收判定】：🔴 退回修改 (REJECT) 或 🟢 准予出貨 (ACCEPT)
2. 【三大關卡驗收明細（含具體程式碼證據）】
3. 【複製貼回 AI Studio 的一鍵修正指令】
EOF

agy --version

接著在終端機輸入 agy 啟動（進入後可輸入 /model 查看或切換目前使用的模型）：

agy

STEP 4

把驗收回饋丟回 AI Studio 修正 ＆ 二次複驗

看到終端機印出 🔴 退回修改 (REJECT)（例如字體太小、缺少 LINE 連結、無效假按鈕）後，複製 agy 產出的修正指令（或複製下方標準修正指令）貼回 https://ai.studio 修改： 

我們的技術長透過 Antigravity (agy) 驗收了你剛才寫的網頁，判定為「🔴 退回修改」。請根據以下三大驗收要求修正 index.html：

1. 【修正字體大小（60歲長輩手機友善）】：全站內文字體大小請全部調大至 18px (1.125rem / text-lg) 以上，主標題請用 30px 以上。請移除所有 text-xs、text-sm 或小於 16px 的微字設定。
2. 【補上真實 LINE CTA 轉換按鈕】：請在首頁首屏與網頁底部各加上一個醒目的行動呼籲按鈕，按鈕文字為「立即加入【彰化旅行+】LINE 好友，掌握《爌肉之城》最新資訊」，並將連結 (href) 設定為：https://lin.ee/changhuatravel （加上 target="_blank"）。
3. 【移除無效假按鈕與未授權優惠】：請移除所有連往 # 的無效按鈕或假表單，並確保內文沒有任何未經授權的折扣、免運或免費贈品資訊。

請輸出修正後的完整 index.html 程式碼。

💡 AI Studio 修正完成後，再次把新版網址或新版程式碼丟回 agy 複驗，確認拿到 🟢 准予出貨 (ACCEPT)！

STEP 5

換你上場（一）：到 AI Studio 用提示詞製作你自己的官網

現在輪到你當產品主人！請前往 https://ai.studio，挑選一個你想推廣的主題（例如：在地美食店家、社群小聚招生、咖啡店新品上市、個人品牌網站、地方旅行企劃），複製下方提示詞範本並填入你的構想，做出第一版官網： 

請幫我寫一個單一檔案（Single-file HTML，包含 CSS 與必要的 JS）的行銷推廣官網：

- 【推廣主題】：（請填入你的主題，例如：鹿港老街深夜手沖咖啡館）
- 【目標客群】：（請填入對象，例如：週末來彰化旅遊的旅人與在地朋友）
- 【核心亮點】：（請填入 2~3 個特色，例如：老屋改建、自家烘焙、營業至凌晨 1 點）
- 【行動呼籲 (CTA)】：請引導使用者點擊加入我們的官方 LINE 帳號（連結：https://lin.ee/請換成你的連結）

請直接輸出完整的 index.html 程式碼。
STEP 6

換你上場（二）：調整 agy 的 SKILL.md，用你自己的驗收標準把關！

每個專案的驗收標準都不同！現在請回到 Google Cloud Shell（若還在 agy 裡，請先輸入 /exit 回到一般終端機），複製下方指令直接覆寫原本的 SKILL.md，把裡面的關卡換成你自己的驗收標準： 

cat << 'EOF' > ~/kbp-lab/.agents/skills/website-audit/SKILL.md
# Metadata
- Name: website-audit
- Description: 使用我自訂的三大驗收標準，審核我的專屬行銷官網是否達到可出貨品質。

# Goal
你是一位嚴格把關出貨品質的技術長。請針對我提供的網站網址或 HTML 原始碼，依照下方三個自訂關卡嚴格驗收，並直接在終端機印出驗收報告。

# Workflow
1. 關卡一（品牌主題與 CTA 轉換檢查）：
   - 檢查網頁是否清楚呈現我的推廣主題與核心亮點。
   - 檢查行動呼籲 (CTA) 按鈕是否使用真實有效的連結（不可連往 # 或空連結）。
2. 關卡二（使用者手機閱讀體驗檢查）：
   - 檢查內文字體大小是否維持在 18px (text-lg / 1.125rem) 以上，手機版排版是否清晰易讀。
3. 關卡三（我的自訂護欄限制 Guardrails）：
   - 檢查 AI 是否擅自捏造了未授權的折扣、免費贈品、抽獎或錯誤的營業資訊。

# Output Format
請直接在終端機畫面印出：
1. 【技術長驗收判定】：🔴 退回修改 (REJECT) 或 🟢 准予出貨 (ACCEPT)
2. 【三大關卡驗收明細（含具體程式碼證據）】
3. 【複製貼回 AI Studio 的一鍵修正指令】
EOF

cat ~/kbp-lab/.agents/skills/website-audit/SKILL.md

💡 覆寫完成後，再次輸入 agy 啟動，把你在 STEP 5 做好的官網網址或原始碼餵給它：請使用 website-audit Skill 驗收我的網站...，看看你的官網能不能順利通過你自己的驗收標準！

🎓 結語：帶走的東西

代理人開發時代，不是把責任交給 AI，而是把任務交給 Agent，把判斷與責任留在人手上。
工具每年都會換，但今天練習的這套「定義規格（Brief）→ AI 快速原型（AI Studio）→ 封裝驗收標準（SKILL.md）→ 嚴格審查出貨（Antigravity）」方法論不會過期！

🛠️ 常見問題排除 (Troubleshooting)

Q1：輸入 agy 出現 command not found？
請重新執行 export PATH="$HOME/.local/bin:$PATH" 載入環境變數。

Q2：要怎麼修改 SKILL.md 裡面的文字？
除了可以直接改動 STEP 6 的指令區塊貼上覆寫外，也可以在 Cloud Shell 輸入 nano ~/kbp-lab/.agents/skills/website-audit/SKILL.md 直接編輯（按 Ctrl+O 存檔、Enter 確認、Ctrl+X 離開）。

Q3：如何離開 agy 互動模式？
在 agy 中輸入 /exit 或按下 Ctrl + C 即可回到一般終端機。
